# 素材要求

## 必须有

| 素材 | 要求 | 不符合时 |
|---|---|---|
| 口播原始视频 | 竖屏 9:16（1080×1920 或 2160×3840 都行），30 或 60 fps | 横屏：本 Skill 不处理，告诉用户先裁成竖屏或重录 |
| 画面 | 单人、正脸或微侧脸出镜，固定机位 | 多人：圆圈只能跟一个人，先问跟谁；人大幅走动：圆圈要逐段测脸，工作量变大 |
| 声音 | 人声清楚，**不带背景音乐** | 有 BGM：包络找不准切点，请用户给没加音乐的原始录音；底噪大：可提议 ChatCut 的人声隔离（先问） |

说错、重说、一句录好几遍都没关系，粗剪会挑出完整的一遍。

## 可选

| 素材 | 用途 |
|---|---|
| 脚本/文案原文 | 口播说到「这段提示词」「这几条」时，把原文上屏，不用自己概括。没有也能剪，动效文字全部取自实际说的话 |
| 特别想强调的句子 | 优先做成大字卡片 |

## 不需要

- 背景音乐：口播默认不铺 BGM。
- 音效：自带真实录音（Freesound CC0，可商用、不用署名），其余由代码合成，不用另找。
- 字体：ChatCut 按名字自动下载，不用装。
- 封面、标题：本 Skill 只剪片子。
