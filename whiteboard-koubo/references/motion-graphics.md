# 白板便签风动效

模板在 `assets/whiteboard-mg/`。开工时把 `lib.jsx`、`scenes.jsx`、`ring.jsx`、`board.jsx` 复制到项目工作目录（`read_project` 的 `projectHome.workspacePath`）下的 `mg/`，`theme.jsx` 用用户保存的风格包 `~/.whiteboard-koubo/theme.jsx`（没有时见 [theme.md](theme.md)「存在哪」），每段动效一个 `.jsx` 放在旁边。
**先看 [scenes.md](scenes.md)：清单、划掉替换、步骤、聊天、顶部卡片这 5 类只写 SPEC。** 下面的原则和排查清单对场景段落和手写段落都适用；手写时用 `import ... from "./lib.jsx"` 引公共组件。

## 风格

- 纸张、配色、字体、相框、出场方式都来自风格包 `theme.jsx`（见 [theme.md](theme.md)），`lib.jsx` 据此算出 `C`、`MARK/HAND/BODY`。要换风格改 `theme.jsx`，不要在各段里另写颜色和字体。
- 手写段落里的歪斜角度用 `jit(key, 幅度)`，出场用 `enter(进度, key)`，这样也跟着风格包和每条视频的 `seed` 变化，不要写死 `rotate(-3deg)`。
- 字体：标题 `LXGW Marker Gothic`（`MARK`），手写 `Long Cang`（`HAND`），正文 `Noto Sans SC`（`BODY`）。
  `MARK` 缺字时会回退成怪字形（例：「个」），这类字单独用 `BODY`。
- 风格边界：不用深蓝发光网格、英文等宽字标签这类科技风元素；可以往奶油暖调手帐风靠。
- 字体只写名字，由 ChatCut 自动加载，不要随包附带字体文件或写 `@font-face`（见 chatcut-notes.md「字体」）。
- 已知局限：圆圈位置 `CIRCLE` 是写死的常量（右下角）。

## 版式

| 版式 | 画面 | 示例 |
|---|---|---|
| A | 人物全屏，动效是顶部卡片叠层（V3） | `example_overlay.jsx`（开头钩子） |
| B | 全屏动效在底层（V1，用 `Paper` 打底），人物缩成右下圆圈在上层，外加 `ring.jsx` 相框 | `example_background.jsx` |

版式切换点落在人物片段中间时，先用 `split_item` 切开（见 chatcut-notes.md）。

## 整板运镜（风格包 `camera: "board"`，可选）

整条片子共用一块大白板：每段全屏动效（版式 B）占白板上的一格，按蛇形排开（第一行从左往右，第二行从右往左，镜头每次只挪到相邻的一格）。切到下一段时，镜头从上一格拉远、平移、再推近到新的一格，之前写的内容都留在板上；第一段从稍远处推近开场。版式 A（人物全屏）的段落不上白板。

段落的写法不变（SPEC 照写，手写段落照常用 `Paper` 和 `useT()`），多出来的只有这几步：

1. `board.jsx` 和其他模板一起复制到 `mg/`；`theme.jsx` 里写 `camera: "board"`。
2. 跑 `scene_cues.py` 时把**所有**全屏动效段落都列上（手写的标 `:B`），它会额外生成 `board_data.jsx` 和每段一个 `cam_<段名>.jsx`，并列出每个该放在哪。
3. **时间线 V1 上放 `cam_*.jsx`，不放段落文件本身**：每个 `cam_*.jsx` 用 `push_asset` 推一次，起始帧和时长与对应段落相同。之后改段落、重跑脚本都会自动更新，不用重新推；新增段落时只推新出现的 `cam_*.jsx`。
4. 想让观众看一眼整块白板（讲到一半做小结，或结尾回顾），在参数里加 `overview@起始帧+时长帧`（2–3 秒）。它也算一段全屏动效：人物缩进圆圈，V1 放 `cam_overview.jsx`。一条片子用一次就够。

注意：

- 每一格里的版面和单独一页完全一样，安全区和 `scene_cues.py` 的检查都照旧。
- 镜头移动约 0.7–1.1 秒，从这一段的起点开始，和人物缩进圆圈同时发生；这期间出现的标题会边移动边出现，不用改时间。切段处自动配嗖声（紧挨着的两段之间也有）。
- 改了任何一段的起始帧、时长，或者增删全屏动效段落，都要重跑 `scene_cues.py`：白板上每一格的位置按先后顺序排。
- 手写段落要 `export default` 一个组件，时间用 `useT()` 取，不要直接用 `useCurrentFrame`（脚本会检查）。
- 白板上超过 9 格时，总览里每格会很小。

`Paper` 在圆圈后面留了一块柔和的阴影，版式 B 的内容要避开圆圈区域（圆心 (770,1480)、半径 160）和字幕区域（top 1716 起）。

批量做之前：先出一张版式样图让用户确认圆圈和字幕位置，再做一段样图让用户确认风格，然后才铺满。

## 动效原则

- **说到哪个效果，画面就演示哪个，卡在对应的字上。** 关键动作的时间（例如 `Hand` 写完的时刻）要对着口播里那个字。
  动效内时间 = 那个字在时间线上的时刻 − 这段动效的起点。字在时间线上的帧 = 所在片段的 `tl` + (字的源时刻 × fps − `srcF`)（取自 `cut.json`）。
- **讲到的具体东西要真的出现在画面上。** 口播逐个点名的（几种纸张、几个工具、几个步骤），画面就逐个展示那个东西本身（样图、截图、实物照片），并且在说到它的那个字上出现；只写一行字代替不算。做之前先对照 SKILL.md 第 3 步的内容对照表。
- **没说的内容不要上屏。** 例：开头钩子里有一个没说到的「没用」章，删了。
- 口播指向脚本原文时上原文，不要概括（见 workflow.md §4 和 `example_fulltext.jsx`）。
- 单段动效 8 秒以上，中间考虑切一次人物全屏，或者压缩。
- 开头 3 秒钩子的一个做法（`example_overlay.jsx`）：顶部卡片先展示问题（「用了去AI味 skill？→ 脚本还是一股子 AI 味」），说到「关键不是去AI味」时划掉，右侧便签出「+ 人味」。

## Remotion 约束

- **时间一律用秒**：`useT()` 返回 `t = frame/fps`，延迟、时长、缓动都按秒写，不要硬编码帧数，这样 30fps 和 60fps 表现一致。
- 一个文件只 export 一个根组件；共用的小组件放 `lib.jsx`（否则 push_asset 报错，见 chatcut-notes.md）。
- `lib.jsx` 里的 `ECG`：`mode:"flat"` 是一次微弱心跳后拉平，`"beat"` 是三次心跳。

## 小动作（`lib.jsx` 里的组件，场景和手写段落都能用）

| 组件 | 用在什么时候 | 场景里怎么用 / 手写段落配的音效（写进 `--extra`） |
|---|---|---|
| `DrawCircle({t,a,x,y,w,h})` | 手绘圈住重点（一个词、一个数字、截图上的一块） | 清单条目 `"mark":"circle"`；手写段落 `scribble 0.45` |
| `Wavy({t,a,x,y,w})` | 波浪下划线，比荧光笔更「强调这句话」 | `scribble 0.4` |
| `CurveArrow({t,a,x1,y1,x2,y2,bend})` | 弯箭头，从说明指向对象 | `scribble 0.4` |
| `Erase({t,a,b,x,y,w,h})` | 橡皮擦把一块内容擦掉（口播说「这个不要了」「忘掉…」时）。擦过的地方重画同一张纸，牛皮纸、软木板上也看不出补丁 | 清单条目 `"mark":"erase"`；手写段落 `erase <擦的秒数>` |
| `Doodle({t,at,kind,x,y,size})` | 手绘小图标：`bulb` 灯泡（想法）· `question` · `exclaim` · `star` · `fire`（火了、爆款）· `heart` · `bolt`（快）· `check` · `eyes`（注意看） | 任何场景 `"doodles":[…]`（见 scenes.md）；手写段落 `scribble 0.4`（`check` 用 `tick`） |
| `Note({…, kind})` | 便签款式默认跟风格包的 `note`；个别便签想不一样时传 `kind`：`tape` `sticky` `pin` `masking` `torn` `fold` `clip` | — |
| `Note({…, out})` | 便签给了 `out` 秒数就在那一刻被撕走飞出（「这条划掉」「下一个」） | 便签墙条目 `"out":秒`；手写段落撕走用 `tear`，揉掉的意思用 `crumple`，便签贴上用 `paper` |
| `Stamp` / `RectStamp` | 圆章 / 方章，文字自定，如「通过」「踩坑」「重点」「NEW」 | 任何场景 `"stamp":{…}`；手写段落 `stamp` |
| 胶带、回形针把东西贴上 | 截图、照片、卡片被胶带贴住的那一下 | `tape` |

控件要符合含义，和场景的要求一样：图标只在口播说到对应意思时出现，不当装饰随手撒。

## 人物镜头（ChatCut 关键帧，不是动效文件）

人物画面本身也要有变化，不然版式 A 就是一个固定机位。用 `scripts/person_moves.py` 生成 `edit_item` 的 `keyframes` 数组：

| 动作 | 什么时候用 | 命令 |
|---|---|---|
| 推镜头 `push` | 版式 A 里说到重点句、金句、反转；一条片子 2–4 次 | `person_moves.py push --item <人物片段id> --start <帧> --end <片段结束帧> --face <脸cx>,<脸cy> [--zoom 1.12] [--out 0.4]` |
| 轻震 `shake` | 重音、「注意」「但是」这类转折的那个字；一条片子 1–2 次 | `person_moves.py shake --item <id> --at <帧> [--amp 12]` |
| 缩进圆圈 `shrink` | 版式 A → B 的切换点，替代硬切 | `person_moves.py shrink --item <版式B人物片段id> --start <它的起始帧> --to '<circle_layout.py 的输出>'` |
| 放大回全屏 `grow` | 版式 B → A 的切换点 | `person_moves.py grow --item <版式B人物片段id> --end <它的结束帧> --frm '<circle_layout.py 的输出>'` |

- 帧号是时间线上的绝对帧。`--face` 是脸在**画布**上的坐标（找脸见 chatcut-notes.md「人物圆圈」）。
- 同一片段先推镜头再轻震时，轻震要用推近后的位置：`--base=<left>,<top>,<width>,<height>`（push 输出里放大后的那组值），否则会跳回原位。
- shrink/grow 之前先用 `edit_item updates` 把那段的 `borderRadius` 设成圆圈的值（160，拍立得相框是 8）。缩放刚开始的一瞬间全屏画面带圆角，0.4 秒内就过去了。
- 推镜头放大 12% 左右就够明显；超过 20% 手机上会显得糊。
- 改完用 `preview_timeline` 抽动作中间的帧看一眼。


## 每段做完的抽帧排查清单

这些都是实际做片时抽帧发现并修掉的问题。只看静止帧看不出过程中的重叠，要抽动画过程帧。

| 现象 | 原因 / 修法 |
|---|---|
| 文字被挤成竖排 | 容器没设 `whiteSpace:"nowrap"`（标签、播放量标签都出过） |
| 手写字被屏幕边缘裁掉 | 估算宽度，必要时左移（例：「活起来了！」） |
| 装饰字被便签盖住一半 | 直接删（例：「得分：」） |
| 动画时间卡不上字 | 按上面的公式重算，对着口播那个字 |
| 元素进入圆圈区域或被字幕盖住 | 挪开或缩小 |
| 动画过程中元素互相重叠 | 抽过程帧检查，错开出场时间或位置 |
| 画面上出现没说的内容 | 删 |
| 同音错字跟着转写做错 | 按语义改（见 workflow.md §4） |
