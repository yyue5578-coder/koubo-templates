# 改动记录

版本号写在 `SKILL.md` 开头和本文件夹 README 顶部。更新方法见 README「更新」。

## 1.0.2（2026-11-21）

- 只改说明，不改功能：写清 ffmpeg 只有 Windows 需要，macOS 用系统自带的 afconvert，不用装。README 的「需要准备」表、`SKILL.md` 的环境检查步骤、`setup.md`、`workflow.md` 和 `envelope.py` 开头注释都已统一。macOS 上 AI 不会再提示安装 ffmpeg。

## 1.0.1（2026-11-20）

- 字幕上移到人物圆圈正上方（y 1200–1290）。原来在画面最底部（top 1716），发到抖音、小红书后会被博主 ID 和标题压住；现在字幕底边离画面底部约 630 px，标题再长也压不到。
- 全屏动效的内容区下沿从 1240 收到 1190，给字幕让位；思维导图整体上移，左下手写句改为只写一行；评论区手写句按行数往上推；左下角小图标上移。
- 验收单新增「字幕位置」：字幕底边低于 y=1440 时报错。

## 1.0.0（2026-11-19）

第一个分享版。

- 粗剪：按声音波形定剪辑点，收紧气口；一句话录了几遍时挑完整的一遍。
- 动效：12 种场景模板，只填内容；圈重点、波浪线、橡皮擦、手绘小图标等小动作。
- 风格包：6 种纸张、6 套配色、3 种标题字、4 种手写字、5 种人物相框、8 种便签款式、3 种出场方式、3 种书写音效。挑好的风格包存在 `~/.whiteboard-koubo/theme.jsx`，更新 Skill 不会丢。
- 整片一块白板（可选）：每段动效写在大白板的一格，切段时镜头平移，可加整板总览。
- 人物镜头：推镜头、轻震，切到动效时缩进右下角圆圈。
- 字幕：改同音错字，画面已有大字处自动隐藏。
- 音效：37 条 Freesound CC0 真实录音加代码合成，响度导出后实测。
- 稳定性：动效时间按「说到哪几个字」由脚本计算；场景字段、文字长度、场景轮换由脚本检查；交付前出验收单，有一项不过就不交付。
- 稳妥做法：动效前先列「口播讲到的东西 → 画面上必须出现的东西」对照表给用户确认；全程只导出两次；不删文件、改为直接覆盖；ChatCut 连不上时停下说明，不自己写连接程序。
- 验收单新增两项：人物在圆圈里时底下有没有动效、人物片段有没有被切碎。
