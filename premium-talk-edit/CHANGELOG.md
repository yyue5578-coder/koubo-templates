# 更新记录

## 0.2.0（2026-11-23）

- 新增 3 种 B 版式卡片：`line` 折线图（说到趋势、变化）、`trio` 三合一（一句话点名清单、对比表、聊天记录）、`savescore` 省时间加分数（先说省时间，再说质量从几分提到几分）。三张都有自动音效规则，`gk_cues.py --check-jsx` 能核对字段；`trio` 的对比表表头和两句聊天气泡可以用 `tableHead`、`chatAsk`、`chatReply`、`chatHl` 改。演示合集里加了这 3 张的虚构示例；预览图 `cards.jpg` 还没更新。
- 支持 Windows：说明书写清 Windows 上的做法（装 ffmpeg、设 `PYTHONUTF8=1`、用 `python`/`py`、找脸和抽帧改用 ChatCut 抽帧）；排错文档补了 Windows 常见报错。
- 安装更简单：对 AI 助手说「帮我安装这个剪辑 Skill：<仓库链接>」即可，INSTALL.md 里有给助手看的安装步骤。
- 版权人改为「吃token的皮卡秋」，补上反馈渠道（GitHub Issues）。
- **许可改为 CC BY-NC 4.0**（和同仓库的白板便签风一致）：模板本身不能拿去卖，用它剪出来的视频可以自由商用。0.1.0 只打包、没有公开发布过。
- 发布在模板合集仓库 koubo-templates 的 `premium-talk-edit/` 文件夹。
- 兼容：只新增字段，没有改名或删除，旧 SPEC 不用改。

## 0.1.0（2026-11-20）首个公开版本

- 25 种信息卡（版式 A 4+5、B 数据 8 + 原文/互动 5、C 全屏 3 种），表格和时间轴内容多时自动分页 / 改竖排 / 可选全屏版式。
- 风格包 8 项可换（约 9.2 万种组合），6 套推荐组合；银灰、酒红配色做了专门处理。
- 卡片时间用 `say`（口播原话）写，`gk_cues.py` 自动换算并检查。
- 音效池：8 类 24 个音效，`gk_bed.py` 按场合自动分配，响度跟人声走。
- 版式切换：`gk_layout.py` 生成上卡下人的人物下移关键帧和全屏讲解的人物圆窗。
- 验收：`final_check.py` 核对时间线结构、人物位置、圆窗、人声重叠、音效响度。
- 已知限制见 README「已知限制」。

### 兼容性约定

- SPEC 字段只增不改名；要改名或删除会写在这里并标「不兼容」。
- `pool.json` 的 `rules` 可以自己改，升级时覆盖文件夹前先备份。
