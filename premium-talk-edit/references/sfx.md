# 高级感干货风 · 音效选择规则（给剪辑的 AI 助手）

音效池（`assets/sfx-pool/`）有 8 类音色，每类 3 个，全部来自 Freesound（CC0 / CC BY），都保留。剪辑时不需要用户逐个挑选。规则交给 `gk_bed.py --pool` 执行，AI 助手只需要按下面的流程操作，在需要时做少量人工指定。

## 一、流程（每条视频都一样）

1. 每段动效的 SPEC 写好，按口播原话写 `say`。
2. 运行 `gk_cues.py 段.jsx@起始帧+时长帧 … --words tl_words.json -o cues.json`。⚠ 全部处理完再往下。
3. 量人声：对**不含音效**的时间线导出一次音频，`measure_mix.py <导出>` 得到「语音段 50 ms RMS 中位数」，记为 `<dB>`（音频导出整体比视频导出低约 3 dB，人声和音效一起抬，相对值不变，照常用音频导出测的值）。
4. 先看分配：`gk_bed.py --pool <Skill 目录>/assets/sfx-pool/pool.json --cues cues.json --seed <视频名> --voice-median <dB> --plan`。
5. 出音轨：`gk_bed.py --pool <Skill 目录>/assets/sfx-pool/pool.json --cues cues.json bed.wav --seed <视频名> --voice-median <dB> --total <片长秒>`。`push_asset` 推 WAV 放音频轨。
6. 交付时附上同目录生成的 `bed_CREDITS.txt`（本条用到的、需要署名的音效）。告诉用户：音效是规则自动挑的，AI 听不到，请用户听一遍。

`--seed` 一律用视频名，不要用固定值。同一个视频名每次生成的结果完全一样，重剪不会变；换一个视频名就换一套组合。

## 二、规则怎么挑（脚本已执行，这里说明原因，便于判断和调整）

### 1. 按场合分角色：同一条视频里，同一个动作的声音不变

`gk_cues.py` 会给每个音效点标上场合。同一场合在一条视频里固定用一个变体。观众会把「这个声音 = 这个动作」联系起来，节奏才稳，所以不要每次随机换。

| 音色 | 场合（按优先顺序） |
|---|---|
| whoosh 转场嗖声 | 上卡下人底色展开 · 钩子/章节/开场 · 全屏讲解/片尾进场 |
| pop 卡片弹出 | 卡片进场 · 气泡/标注 |
| tick 轻点 | 列表逐项 · 打勾 · 框选 |
| hit 数字落定 | 主数字落定（大数字、公式结果、数字钩子） · 次要数字落定（第二个数、百分比环、身份条数字） |
| swipe 纸张/荧光笔 | 荧光笔 · 划掉 · 翻页；文件滑入固定用最长的那个（纸张滑动声） |
| ok 完成提示 | 清单结论 · 片尾收藏 |
| no 错误提示 | 打叉 · 风险提示 |
| key 按键 | 打字时 3 个轮换，相邻两下不重复 |

### 2. 同类不同场合，尽量用不同变体

同一类音色的不同场合，会分到不同的变体。例如底色展开用 2 号嗖声，钩子用 3 号，全屏进场用 1 号。一条片子里能听到 8 类 × 2–3 种声音，比全片只用一个声音更丰富，又不会乱。

### 3. 两条约束：保证高频的不累、重音压得住

- **高频场合不用同类里最长的那个**：底色展开、卡片进场、列表逐项、打勾、荧光笔一条片子里会出现几十次，长音效听多了会累。
- **重音场合不用同类里最短的那个**：钩子进场、主数字落定需要分量，太短压不住。

长短按 `pool.json` 里量测的有效时长判断，不靠耳朵。

### 4. 换视频，换组合

满足上面约束的分配有多种，用视频名算出用哪一种。每类有 2–6 种分配，8 类合计约 16 万种组合，同一个账号连发的视频声音不会千篇一律。

### 5. 连发自动变化

- 同一段里 1.5 秒内接连出现的列表逐项、打勾、气泡，音高逐个升高 3%，最多 9%。听起来是一级一级往上走，不是机关枪。
- 每次出现都有音高 ±2%、音量 ±1.5 dB 的轻微浮动。

### 6. 密度上限

- 任意 10 秒内轻点最多 7 个。超出时，去掉连发里除第一个以外的。
- 生成音效点时已经做过的处理：同类同时出现只留一个；间隔不到 0.2 秒的连串轻点只留第一个；卡片弹出和嗖声相隔不到 0.25 秒时不配卡片弹出。

### 7. 响度：跟着人声走

每类音色的响度 = **人声中位数 + 固定差值**（取该音效最响的 50 ms 窗口），这是实际剪片中反复调到「听得清又不盖住说话」的起步值，不要从 −15～−20 dB 起步（那样会太小）：

| 音色 | 相对人声 | 场合加减 |
|---|---|---|
| hit 数字落定 | +6 dB | 主数字 +2，次要数字 −2 |
| pop 卡片弹出 | +4 dB | 气泡 −2 |
| tick 轻点 | +3 dB | 框选 +1 |
| ok / no 完成 / 错误 | +3 dB | 风险提示 +1 |
| swipe 纸张/荧光笔 | −2 dB | 翻页 −3，文件滑入 −2 |
| whoosh 转场嗖声 | −1 dB | 钩子 +2 |
| key 按键 | 按峰值：人声 + 17 dB | — |

任何一个声音的峰值不超过 −6 dBFS，整条音轨峰值不超过 −3 dBFS。3 个变体换着用，音量不会忽大忽小（按各自的实测响度对齐）。各音色超长的部分会截断并淡出：嗖声最长 0.8 秒、轻点 0.2 秒、完成提示 0.9 秒。嗖声把峰值对准动作时刻，其余从起音对准动作时刻。`final_check.py` 会实测成片里每类相对人声多响，偏离目标超过 4 dB 报 ⚠，比人声响 9 dB 以上报 ❌。

## 三、什么时候人工介入

| 情况 | 怎么做 |
|---|---|
| 用户说某个声音难听 / 不喜欢 | 在 `assets/sfx-pool/pool.json` 里把那个变体的 `"disabled"` 改成 `true`，`note` 写原因，重跑第 4 步。被禁用的不会再被挑到，以后的视频也一样。 |
| 某一处想用特定声音 | SPEC 里写 `"sfx":[[秒,"pop#3"]]`，指定用 3 号；`#号` 只影响这一处。 |
| 某段不要音效（例如人物情绪很重的段落） | SPEC 里写 `"sfx":false`。 |
| 想加打字声 | SPEC 里写 `"sfx":[[开始秒,"type",时长秒]]`，脚本用 3 个按键声轮换生成。 |
| 用户嫌整体音效太大 / 太小 | 第 5 步加 `--gain -3`（或 `+3`）整体调，不要改单个音色。 |
| 用户嫌轻点太密 | 把 `rules.density.tick.max` 从 7 改小（例如 4），重跑。 |
| 用户嫌某类太大声 | 改 `pool.json` 里 `rules.rel_db` 那一类，每次改 2 dB。 |
| 想要整条片子统一、更克制 | 第 5 步加 `--no-vary` 去掉浮动；或者给其他变体都写 `disabled`，只留一个。 |

不要做的事：
- 不要每次手动挑变体。
- 不要用固定的 seed。
- 不要整体压低到听不见：音效太小是被返工过的问题，要从上表的音量起步。

## 四、音效池清单与署名

- 24 个变体的来源、许可、量测值都在 `assets/sfx-pool/pool.json`。
- 署名总表在 `assets/sfx-pool/CREDITS.md`。CC BY 许可的有 6 个，用到时必须署名：卡片弹出 1、2 号，轻点 2 号，数字落定 2 号，纸张/荧光笔 3 号，错误提示 2 号。
- `gk_bed.py` 每次会把本条实际用到、需要署名的写进 `<输出名>_CREDITS.txt`。

想扩充音效池（维护者功能，剪片不需要；需要另装 sfx 技能去 Freesound 找音效）：用 sfx 技能 `find` 新候选 → `take` 取回 → 运行 `scripts/make_pool.py` 重建（`rules`、`disabled` 和 `note` 会保留）。
